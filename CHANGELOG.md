## Pre-release history (unversioned, 2026-08)

The project was built in adversarially-verified phases before its first tagged
release; the full record lives in `NOTES/restart.md` and the `[claude]`-prefixed
commit history.

- **Phase 2A–2B** — FluSight data layer on git-vintage truth; WIS scorer
  cross-validated against the official pipeline (relative WIS 0.999989).
- **Phase 2C** — pooled LightGBM quantile model; beats FluSight-baseline.
- **Phase 2D** — three-season league tables; LightGBM wins 2025-26 (relative
  WIS 0.609 vs UMass-flusion 0.625), loses the two earlier seasons — printed.
- **Phase 2E** — submission automation: `prime-radiant epi forecast|validate`,
  hub-valid CSV writer, registration metadata, five-gate inert live path.
- **Phase F** — Gradio dashboard on a precomputed serve bundle; deployed to
  Hugging Face Spaces; FluSight registration PR opened.
- **Phase G** — release hardening: CI, pre-commit, Dependabot, release and
  publish automation, Docker, docs, and the public flip.
